## 📋 Descripción

Aplicación frontend desarrollada con **Angular 9** y **TypeScript** para el sistema **IVULES**, una plataforma web para el seguimiento clínico-laboratorial de pacientes con y sin  Lupus Eritematoso Sistémico (LES).

Este frontend proporciona una interfaz de usuario responsive e intuitiva para:
- ✅ Registro y consulta de pacientes
- ✅ Seguimiento clínico por visitas
- ✅ Carga de resultados de laboratorio
- ✅ Visualización de historial clínico
- ✅ Generación de reportes en Excel
